# Agent Plan Editor

React + TypeScript + Vite 的响应式编辑器，复用 Core、AI 与存储包。

设置上方的 **Document** 打开[正式手册](../docs/handbook/introduction.md)，包含快速入门、完整流程语法、脚本、工具、CLI 和调试。目录、阅读器、正文和搜索索引分开加载；助手 `project.docs` 使用同一套内容。示例只导入文件，不自动执行。

```sh
pnpm install
pnpm editor
```

生产构建可运行根目录 `pnpm build`；单独构建 Editor 前需先构建 core、ai、storage。

## 三个界面

- **Agent**：正常消息对话、发送/停止；抽屉管理所有对话，设置集中到抽屉底部入口。执行选中的流程，将消息写入 `chatIn` 输入，并将 `chatOut` 输出显示为回复：字符串渲染 Markdown，数字、布尔值、null、对象和数组显示为 YAML 代码块。只有 `fields.chatOut` 开启 output 的流程才会出现在 Agent 选择器中，其他流程在 Editor 调试。
- **Library**：平铺流程卡片，支持搜索、新建、上传 JSON/YAML（每个文件最多 5 MB）、下载 YAML、重命名、确认删除。每次上传新建独立记录，同名文件不会覆盖已有流程；导入内容通过 Core 校验，外部 imports 保留但暂不能在浏览器执行。
- **Editor**：步骤列表、参数表单和变量面板。参数采用名称 + 输入栏，自动推断数字、布尔值、JSON/YAML 对象和列表；调用参数按名称逐行显示。支持弹窗新增/编辑、列表确认删除、手柄拖拽排序、嵌套分支、一次修改撤销和单步测试；变量在上，步骤在下，运行工具栏固定底部。

步骤点击“应用步骤”后写入 Library；有效的变量设置自动保存，列表运行值只影响当前调试，不写入流程默认值，不再提供保存变量按钮。无效输入明确报错，不称为已保存。变量名变更不自动重写步骤引用。运行数据直接复用变量面板，暂停时修改值通过 Core setFields 生效，不重置运行进度；最多保留 300 条步骤记录，每次连续调试最多推进 2000 步后暂停。Agent 页超过 2000 步则失败，避免对话无限等待。

## 默认本地 Agent

Agent 的内置入口是独立的 AgentPlan助手，按设置选择 OpenAI、Anthropic 或本地模型。首次 Library 模板及新建流程仍使用本地记忆对话示例，包含可编辑的 memory.init 系统提示、time.now/web.search/web.fetch 工具与显式工具循环。系统提示仅保留通用行为要求，具体查询用法由工具说明提供；不保证小模型正确调用工具。

新建流程从同一模板开始。Agent 的“新对话”生成独立 UUID，每轮传入 `threadId` 和 `chatIn`；不自动提供 memoryKey。记忆结构和存储 key 由流程自行管理。Editor 调试可手动填写 threadId。

## 数据保存

- 流程定义：IndexedDB `agent-plan-library`，按稳定 ID 保存；重命名不改变 ID。
- 原始对话记录：通用 IndexedDB `agent-plan-storage` 的 `threads/<threadId>`，每线程一条，包含 id、flowId、title、messages。流程可用 storage.read 读取。
- 对话界面索引：`agent-plan-conversations` 的 `thread-index/<flowId>`，只保存 activeId 和 threadIds；聊天内容不再按流程打包保存。
- 流程的通用存储：原有 `agent-plan-storage`，通过 key 分组。
- 模型凭据、下载许可：仅当前页面内存，刷新后重新设置，不写入导出的流程。

页面刷新后已保存流程、对话和记忆仍保留；执行现场不恢复。数据属于当前浏览器和站点，清理站点数据会丢失。重要流程请下载备份；尚无 Git 同步、文件夹关联、多设备同步或通用存储管理页面。

## 工具与限制

已注册 `llm.local`、`llm.openai`、`llm.anthropic`、`storage.read/write/delete/list`、`tokens.count`。在 Editor 添加调用步骤，选择工具名称后编辑参数。使用方法见 [AI 工具](../agent-plan-ai/README.md) 和 [存储与计数](../docs/storage-and-tokens.md)。

模型调用仍复用共享工具；本地模型在 Worker 中运行。停止调用无法回滚之前已发生的存储或外部副作用。外部子流程加载、浏览器 script.run、通用工具加载和 Agent 工具循环仍未实现。当前的 Agent 对话页运行用户流程，不是操作编辑器的内置助手。

## 验证

`pnpm --filter agent-plan-editor test`、`pnpm --filter agent-plan-editor build`。自动测试覆盖 JSON/YAML 导入、错误文件拒绝、默认对话入口、thread ID 隔离、步骤调试记录。真实 Chromium 已验证上传、重命名、下载、刷新持久化、流程驱动对话、步骤及对象变量表单编辑，以及 390px 下三页无横向溢出；不等于真实手机 GPU 验证。


### 多对话与节点展示（2026-10-02）

Agent 支持新建和切换多个 thread，每个流程的会话列表、当前选择和聊天记录保存在浏览器中。新对话不删除旧记录。每轮传入 chatIn 和 threadId，原始对话按 threads/<threadId> 存入通用存储；流程自行决定是否读取历史和怎样保存记忆。旧版对话数据不迁移、不读取、不删除。Editor 调试仍使用流程原始初值。

Library 默认导出可读 YAML，仍兼容 JSON/YAML 上传。19 种基础节点按数据、文本、计算、判断、控制和调用六类着色；卡片优先显示节点名称或调用目标，说明作为辅助文本，参数与详细结果按需打开。


对话流程最小示例见 [chat-echo.yaml](../examples/chat-echo.yaml)。chatIn 接收消息，chatOut 返回回复，无需新增 Core 节点。已有浏览器流程的旧 text 或 prompt/answer 对话约定通过普通 set 步骤迁移，保留原逻辑。

界面遵循信息最小化：Agent 直接选择对话流程和 thread；Library 使用图标操作及名称省略组件；Editor 显示短节点名、类别图标和输入/输出摘要，点击步骤名称打开输入/输出参数与说明弹窗，删除在列表右侧操作。操作图标提供无障碍标签，主要按钮保持 44px 触控目标。


### 参数与单步变量（2026-10-03）

- 参数名在左，编辑栏在右，不再手选类型。`12` 为数字、`true` 为布尔值、`null` 为空值，JSON/YAML 自动解析；`"123"` 保留为字符串。普通文本保留原有空格和换行。步骤中的 `$path` / `$$text` 仍遵循 Core 引用/转义规则；变量初值和调试值保持字面量。
- 变量栏留空表示未设置，填写 `""` 表示空字符串；步骤参数留空表示空字符串。结构语法错误、重复 YAML key、非有限数字等明确报错，不能带着错误保存或运行。
- 变量设置（名称、默认值、说明、输入/输出标记）使用弹窗；有效修改自动保存。列表内输入只修改运行值，删除操作在列表右侧。
- 单步结束后，同一变量面板显示当前值；暂停时改值立即调用 Core `setFields`，下一步使用新值，不改变已记录的步骤快照或流程初始值。运行中禁止修改；完成/失败后可以直接改运行值或再次运行，重置才恢复默认值。保存步骤或变量定义清除进度并保留同名变量的运行值。
- 非 JSON 运行值和未声明的动态变量只读，不把展示摘要伪装成可恢复数据。变量值、执行现场不持久化为可恢复会话。


### Mantine 与 i18n

基础 UI 使用 `@mantine/core` / `@mantine/hooks`（9.6.3），主题见 `src/theme.ts`，组件通过入口 `MantineProvider` 提供。基于现有 Vite 项目接入，不依赖额外后台或 Tailwind；保留产品布局 CSS，菜单、弹层、焦点控制等优先复用组件库。设置使用独立页面，分组直接展开，通过返回按钮回到原界面。

国际化使用 `i18next` 26.4.2 与 `react-i18next` 17.0.15。默认简体中文，可在设置中切换 English；偏好记录在 localStorage 的 `agent-plan.language`，存储不可用时仍能在当前页面切换。语言资源位于 `src/locales/zh-CN.json` 和 `src/locales/en.json`，首版随应用打包，不发起语言资源网络请求。

新增 UI 文案使用 `tr`，当前使用中文源文案作为 key，避免在代码里拼接翻译句子；动态值使用 `{{name}}` / `{{count}}`。组件若脱离 App 单独挂载，应使用 `useTranslation` 订阅语言变更。新增语言时补资源、supportedLngs 和选择入口。不得翻译用户流程内容或协议字段；工具/模型原始消息保持原文。语言切换保留表单草稿与运行状态。

这些依赖均为 MIT 许可；安装时已核对 React 19.3 和 TypeScript 7 的 peerDependencies。测试覆盖资源键与插值变量一致性、语言切换和用户工具标识保真。

### 抽屉与触摸操作（2026-10-03）

- 顶部悬浮标签切换 Agent / Library / Editor；左侧抽屉列出各对话流程的 thread，点击回到 Agent。顶部不再放用户/设置入口，设置仅从抽屉底部进入。
- 手机抽屉通过按钮打开/关闭，点击遮罩也可关闭；滑动手势已移除，后续再设计。桌面抽屉展开时让出主页面空间。
- 输入框上方输入文字，下方选择 Agent 与发送/停止；多模态和语音尚未实现，不展示可用按钮。
- 步骤和变量用 dnd-kit 手柄支持鼠标、触摸与键盘排序；嵌套步骤在各自分支内排序，不跨分支拖动。使用 `@dnd-kit/core` 6.3.1、`sortable` 10.0.0、`utilities` 3.2.2（MIT，React peer >=16.8，包含 ESM 构建），避免自行实现拖拽碰撞和键盘排序。
- 删除流程仅删除 Library 定义，保留既有对话/通用存储；最后一个流程删除后库保持为空，内置 Agent 仍可使用。
- 浏览器验证覆盖弹窗增删、自动保存与刷新、暂停改值、对话切换、键盘/触摸排序与抽屉手势；不代表真实 iOS/Android 或手机模型推理验证。

### 设置与对话管理补充（2026-10-03）

设置只从抽屉底部进入，桌面和手机均为带返回入口的独立页面，采用常规、本地模型、OpenAI、Anthropic 分组，不折叠内容；返回保留原页面与草稿。抽屉使用侧栏折叠图标。

每条 thread 右侧提供删除图标，确认后持久化删除聊天记录；不删除流程或流程自行管理的其他存储数据。删除当前 thread 时选择剩余 thread；删掉最后一条 thread 后保留空列表；显式新建或首次发送消息时才创建新的 thread 与 threadId。运行中禁止删除。

### 紧凑列表与删除修正（2026-10-03）

Library 搜索在左，数量/上传/新建在右，共用一行；手机隐藏数量和按钮文字，保留圆形图标按钮。流程标题右侧显示类型标签，卡片中部预留说明，右下角集中显示操作。点击卡片进入 Editor；名称与说明通过操作按钮打开弹窗修改。变量区取消整体大卡片，变量以无卡片底板的紧凑行展示，保留拖拽、内联值与弹窗设置。对话行整行悬停着色；确认删除弹窗层级高于手机抽屉。纯图标按钮使用圆形底板，颜色与交互含义不变。

对话输入框占满输入区并左对齐；右侧 Agent 选择统一使用带搜索的组件弹窗。Library 桌面搜索限制宽度，上传/新建按钮默认透明，卡片两行之间不加分割线并保持紧凑间距。步骤拖动手柄放在步骤卡片内部，底部运行工具栏在手机与窄屏使用胶囊圆边，显示文字按钮的桌面布局（768px 起）使用小圆角矩形。

Editor 点击步骤中部或变量名称区域进入编辑，行末为带确认的删除按钮；变量值仍可直接修改。

编辑弹窗和设置统一标签在左、输入在右，输入及选择控件使用带边框的样式；名称或步骤类型在最上方，说明置于最后、操作区之前。分组仅使用标题与留白，不使用分割线。步骤类型按调用、变量、控制、文本、数学、逻辑分组并支持搜索；每种节点有独立图标，类型选择器与步骤列表共用，颜色按类别区分。工作台变量输入也使用带边框的样式。分组标题统一加粗，字段标签使用较小的常规字重。变量与步骤仅从列表右侧删除；变量弹窗编辑名称、用途、默认值和说明；外部变量栏始终编辑运行值，不写回默认值。

默认值持久化在流程定义；运行值只保留在当前 Editor。完成或失败后保留运行值，再次运行或单步从这些值开始；仅点击重置恢复默认值。修改默认值不覆盖已有运行值；编辑步骤或变量定义会清除旧执行记录，但保留同名变量的运行值。暂停期间改值通过 Core setFields 更新当前运行，继续执行不重置进度。拖动手柄各状态保持透明底色。

运行值标题与“重置到默认值”“设置为默认值”按钮同排显示。运行值与默认值一致时隐藏两个按钮；设置为默认值将已声明变量的当前 JSON 值写入流程默认值，未设置值移除对应默认值，非 JSON 值不支持保存为默认值。

Editor 对未满足对话约定的流程显示“设置为对话”，补齐 chatIn、threadId 输入及 chatOut 输出，保留已有字段配置和步骤。满足约定后隐藏该按钮；此操作仅配置对话入口，不自动添加模型调用或改写回答逻辑。

顶部导航与底部运行工具栏共用视觉规范：中文名称为对话、流程库、编辑器；桌面显示图标和文字，小屏（小于 768px）仅显示图标并保留无障碍名称。选中项深绿填充，小屏胶囊容器、桌面小圆角矩形。

步骤输入与输出支持变量联想：短单行名称（最多 48 字符）按已有变量筛选，选择补齐 `$`，无匹配时提供新增；多行、长文本、JSON/YAML、数字和 `$$` 转义不显示联想。新增引用在应用步骤时由 Core 收集为流程变量，取消不创建变量。输出框固定显示 `$` 前缀，草稿变量名默认留空，选择建议自动填入名称；输入用 Core 校验，非法内容保留并提示，阻止提交以便修正。调用输出留空表示不保存，必需写入目标的节点应用前仍需填写。

### 按线程保存原始对话（2026-10-03）

通用存储 key 为 `threads/<threadId>`，JSON 数据结构为 `{id, flowId, title, messages}`。消息沿用 `{role, content, format?}`，文字保留 Markdown 原文，结构化回复保存 YAML 展示文本及 `format: "yaml"`。线程 ID 全局生成 UUID，不再使用重复的 initial ID。

运行顺序：先持久化本轮 user 消息，再把 chatIn、threadId 传给流程，完成后追加 assistant 消息。流程可通过模板 `threads/$threadId$` 构造 key，然后调用 storage.read 读取包括本轮输入的记录；不会自动把历史或记忆交给模型。执行失败或停止保留已存的 user 消息，不追加虚构回复；输入保存失败则不执行流程。

不迁移旧对话，也不删除旧数据。旧流程里的 memoryKey 仍是用户字段，不再由宿主赋值。删除线程只删除对应原始记录和索引项，不删除流程自行管理的记忆。

原始记录结构、读取示例及流程与界面的写入边界见 [Editor 原始对话记录](../docs/storage-and-tokens.md#editor-原始对话记录)。

调用目标选择器按调用名第一个英文句点（.）前的 namespace 分组，无句点的放入全局；正在编辑的流程在选项行最右侧显示独立的当前流程标签。列表名称只去掉第一级 namespace（a.b.c 显示 b.c），悬停及选择后的输入框显示完整调用名；分组不改变调用别名或 imports。

远程模型连接参数 baseURL、apiKey、model 在每个调用步骤内填写或引用变量，设置页面不再提供远程连接。outputFormat 默认 text；设为 json 时必须填写 jsonSchema，输出 result 为解析后的值，文本模式的 result 是字符串；模型输出统一为 result、finishReason、usage。直接填写的密钥会随流程保存/导出。

三个 llm 工具统一使用 input 输入：文字作为单条 user 消息，数组保留 system/user/assistant 角色及顺序。旧 prompt/messages 调用参数不再接受；tokens.count 的 text/messages 参数保持不变。

### 内联分组

运行值通过“添加变量”弹窗顶部的“变量类型”选择变量或变量分组，组内也使用同一入口，不再提供独立添加分组按钮。新增变量点击完成后保存，切换类型不会留下未完成的变量；已有变量仍自动保存。支持嵌套、命名和说明分组；通过独立手柄拖动调整顺序，拖到分组标题或组内放置区可移入，拖到外层放置区可移出。分组的折叠按钮与编辑标题分开，右侧解散按钮保留内部变量；变量弹窗不再提供所属分组选择。步骤类型中可添加步骤分组，整理菜单支持放入新分组、移入已有同层组、移到外层及解散保留内容。默认折叠随流程保存、导出；临时展开不写入文档。调试时自动展开下一步或错误所在的组、分支和循环。运行值和步骤面板也可整体折叠。

调用表单使用工具包的 inputs / outputs 接口和内联分组，子流程接口使用 fields 的同一分组结构。运行时默认值显示为 placeholder，预填值单独由 initial 指定。分组说明支持 Markdown；中英文界面均可使用。

变量与步骤共享跨层拖拽：同层占位随目标让位，跨组显示目标占位；步骤可拖入分组、条件分支、循环体，或拖回外层，禁止把容器拖入自身及后代。拖拽未松手不保存流程，取消不改变数据。

拖拽落位以当前可见目标占位为终点，动画完成后才应用结构移动，不依赖排序前的位置 ID。分组与循环卡片中部可直接接收步骤，条件节点使用各分支作为明确接收区；接收区的高度在拖动期间保持稳定。

默认流程统一为本地模型记忆对话，新建、首次初始化和固定内置入口复用 src/example.json。无需 API Key；首次使用需下载模型。上下文独立存储于 memory/<threadId>，不做摘要压缩或自动裁剪，回复最多 512 token。超长输入和工具结果仍可能超过模型 2048 token 限制。Editor 调试时请填写 chatIn 和独立的 threadId。已有用户流程不自动覆盖，可导入 examples/memory-chat.json 或 YAML 使用更新后的示例。

LLM 高级设置支持 tools 名称数组，输出新增 toolCalls/message；tools.execute 已加入调用选择器，按顺序执行并保留各调用结果。静态工具名称自动绑定 Library 导入。参见 [工具调用](../docs/tool-calling.md)。

## 文件工作区与脚本

Library 支持任意文件、文件夹和 ZIP 导入导出；只有经 Core 校验的 JSON/YAML 才作为流程。
普通文本文件可编辑，其他文件保留原始字节供下载。script.run 仅接受 code 源码及 input 参数，通过 import 引用工作区/HTTPS 文件。脚本直接读取全局 input，调用 result(value) 设置输出，未设置返回 null；使用独立 Worker 执行。
路径和动态导入边界见 [脚本与工作区](../docs/scripts-and-workspace.md)。

### 编辑组件

文件库采用 SVAR React File Manager 2.6（MIT），保留原生工具栏、目录树、新建/上传菜单、视图切换和小屏响应式行为，适配现有 IndexedDB 文件接口。桌面双击文件夹进入，手机轻点进入或返回上级；双击流程打开表单，双击文本文件打开 CodeMirror 源码编辑器；目录支持下载为 `.agentp.zip`。只有该后缀的工程包上传时自动解压，普通 ZIP 原样保存。复制、剪切/粘贴、改名、删除使用原生交互；路径引用仍需用户手动更新。原生图标字体由 SVAR 官方 CDN 加载。

CodeMirror 6（MIT）复用于 script.run 的 code 和文件源码，提供行号、高亮、缩进、括号补全、语法诊断、input/result 与相对模块路径补全，以及全屏编辑。Acorn（MIT）负责 JavaScript 语法诊断。浏览器标准 textarea 不具备这些能力，采用现成组件避免自行维护编辑器与文件管理交互。依赖为 ESM，已在本项目 Node 24 / React 19 的类型检查及生产构建中验证；SVAR core 固定 2.6.0，与文件管理器保持同一 Locale context 实例。

## 对话执行记录

每轮回复下方的“执行记录”打开侧边面板，手机使用全屏面板；运行中和失败时同样保留入口。记录来自实际 Core 步骤与宿主调用，包括 tools.execute 内部的工具调用，展示名称、状态、耗时、输入输出摘要和错误。模型回复中的口头说明不视为执行证据。

默认不采集变量快照。“记录变量快照”只影响后续运行，采集有大小限制的执行前后变量摘要，不是可恢复快照。所有记录仅保存在页面组件内存中，不写 IndexedDB 或模型上下文；刷新、离开对话界面后清除。最多保留最近 8 轮，每轮最近 100 条记录及约 128000 字符，总计约 512000 字符；这是记录文本限额，不是浏览器实际堆内存限额。长值和较早记录会截断。运行期间禁止清空，避免正在执行的记录再次出现。

## 本地模型下载管理

设置页提供模型/分词器的开始下载、暂停、继续和进度；下载中在主界面显示同一进度条，可直接暂停。对话的停止按钮终止当前轮及其下载；设置中的释放按钮停止下载并释放模型 Worker，保留已下载数据。暂停不终止对话，继续下载后同一轮继续执行；模型加载/生成的十分钟限制从下载完成后开始。

模型固定到共享 LOCAL_REVISION，网页端权重和 tokenizer 从同一版本加载。HTTP Range 分块下载，每块最多 4 MiB，完整分块与进度原子保存在 IndexedDB agent-plan-model-downloads；完整文件写入 CacheStorage agent-plan-model-files-v1，随后删除临时分块。暂停或停止时最多需要重传当前未完成分块；刷新后在设置里继续，不自动恢复原对话执行。响应范围、总长度及分块长度均检查，服务器不提供可读的 206/Content-Range 时明确报错，避免把错误响应拼成模型。浏览器清理存储或配额不足会影响缓存；完整文件写入缓存时可能暂时同时占用分块和完整文件空间。

模型 Worker 和 tokens.count 共用完整文件缓存，不在推理阶段偷偷下载模型文件；tokens.count 的 tokenizer 实例由 BrowserAiHost 复用，estimate 模式不下载。运行库仍由页面资源加载，不属于模型文件进度。

本地模型默认在首次使用时初始化，对话仅在实际调用期间显示初始化提示与动画。设置中的“后台初始化”默认关闭，开启后提前加载同一推理会话并显示状态；选项保存在此浏览器，刷新后可再次预热。预热不生成消息，不创建对话。释放或关闭预热可停止正在进行的初始化，已下载文件保留；已就绪的会话仍可复用到释放或刷新。

对话运行不会锁住导航：可切页面、切换 Agent/会话、创建空白会话或删除其他会话，回复继续保存到发起运行的会话，原会话显示“运行中”。正在运行的会话需先停止再删除；其他会话可保留输入草稿，当前运行结束后再发送。运行状态只在本次页面内保留，刷新不恢复执行。

AgentPlan助手使用独立 `src/assistant.json`，新建流程仍使用 `src/example.json`。设置可选择自动/OpenAI/Anthropic/本地，配置 API Key、Base URL、模型 ID；自动优先有 Key 的 OpenAI，再 Anthropic，均未配置时本地。远程失败直接报告，不静默回退；远程模型提供基础库工具，本地控制为时间/搜索/HTTP 三个工具。连接配置保存于当前浏览器 localStorage，Key 由宿主注入，不进入流程或记忆；调用步骤显式传入的连接参数优先于设置。远程直连仍要求服务支持浏览器 CORS。
