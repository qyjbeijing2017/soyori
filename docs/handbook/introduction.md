# 什么是 AgentPlan

Agent Plan 致力于让任何人（包括不懂代码的人），在任何设备上（包括移动设备），快速的开发、运行和调试自己的AI Agent。

## AI Agent 的基本结构

一个通用的 AI Agent，结构往往非常简单：**一个 AI 模型、一组工具，以及一个让它们配合工作的流程。**

它通常这样工作：

1. **接收任务**：用户告诉 Agent 想完成什么。
2. **决定下一步**：AI 根据任务和已有信息，决定直接回答，还是调用工具。
3. **执行工具**：例如读取文件、搜索资料、运行代码，并把结果交给 AI。
4. **继续或结束**：AI 根据结果继续行动，直到完成任务，向用户返回结果。

这个“思考 → 调用工具 → 查看结果”的循环，就是许多 AI Agent 的基本工作方式。Agent Plan 帮助你搭建、运行和调试这样的流程。

## AI Plan 是怎么工作的

以一个查询天气的 Agent 为例。

### 流程：一轮问答，运行一次

每发送一条消息，就触发一次流程运行；返回回复后，这次运行结束。

例如，你问“明天北京会下雨吗？”，流程查询天气并回复。再问“后天北京的天气呢？”，同一个流程会再次运行。

### 步骤：把事情拆开做

这个例子的流程分成四个步骤，你可以在编辑器中选择步骤、调整顺序，搭建自己的流程：

1. **理解问题**：让 AI 从问题中提取城市“北京”和时间“明天”。
2. **看时间**：获取今天的日期，把“明天”换成具体日期。
3. **查天气**：请求已接入的天气接口，获取北京明天的预报。
4. **给回复**：让 AI 根据预报，回答是否会下雨。

### 工具：给步骤提供能力

这四个步骤用到三个工具：

| 工具 | 用在哪个步骤 |
| --- | --- |
| `llm.openai` | 理解问题、给回复：调用 DeepSeek 等兼容模型 |
| `time.now` | 看时间：获取当前日期和时间 |
| `web.fetch` | 查天气：请求天气接口，需要接入提供天气数据的服务 |
