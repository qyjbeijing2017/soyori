# 什么是 Soyori

Soyori 帮助你把 AI 和工具组合成能完成任务的助手，也就是 AI Agent。你可以在电脑或手机上编辑流程、运行它，并逐步查看哪里出了问题；不懂编程也可以从示例开始。

你可以自己操作，也可以让内置助手帮你阅读文档、修改文件和测试已保存的流程。

从一个单轮翻译助手开始：[电脑端 Editor 入门](quick-start.md)、[手机端 Editor 入门](quick-start-mobile.md) 或 [YAML + CLI 入门](quick-start-cli.md)。

完成第一课后，继续[快速入门 2：使用记忆](quick-start-memory.md)，再学习[快速入门 3：使用工具](quick-start-tools.md)。两课都包含 Editor 操作、完整 YAML 和 CLI 命令。

一份 YAML/JSON 流程文件的完整内容称为**流程（Flow）**，其中 **字段（Fields）**保存数据，**步骤（Steps）**定义按顺序执行的操作。Editor 用同名区域编辑这两部分，文件格式仍使用 `fields` 和 `steps`。

## AI Agent 的基本结构

一个通用的 AI Agent，结构往往非常简单：**一个 AI 模型、一组工具，以及一个让它们配合工作的流程。**

它通常这样工作：

1. **接收任务**：用户告诉 Agent 想完成什么。
2. **决定下一步**：AI 根据任务和已有信息，决定直接回答，还是调用工具。
3. **执行工具**：例如读取文件、搜索资料、运行代码，并把结果交给 AI。
4. **继续或结束**：AI 根据结果继续行动，直到完成任务，向用户返回结果。

这个“思考 → 调用工具 → 查看结果”的循环，就是许多 AI Agent 的基本工作方式。Soyori 帮助你搭建、运行和调试这样的流程。

## 流程是怎么工作的

以一个查询天气的 Agent 为例。

### 流程：一轮问答，运行一次

在对话页面，每发送一条消息，就触发一次流程运行；返回回复后，这次运行结束。你也可以在编辑器中直接运行流程，不经过对话。

例如，你问“明天北京会下雨吗？”，流程查询天气并回复。再问“后天北京的天气呢？”，同一个流程会再次运行。

### 步骤：把事情拆开做

这个例子的流程分成四个步骤，你可以在编辑器中选择步骤、调整顺序，搭建自己的流程：

1. **理解问题**：让 AI 从问题中提取城市“北京”和时间“明天”。
2. **看时间**：获取今天的日期，把“明天”换成具体日期。
3. **查天气**：请求已接入的天气接口，获取北京明天的预报。
4. **给回复**：让 AI 根据预报，回答是否会下雨。

### 工具：给步骤提供能力

这四个步骤用到三个工具：

| 工具 | 用在哪个步骤 |
| --- | --- |
| `llm.openai` | 理解问题、给回复：调用 DeepSeek 等兼容模型 |
| `time.now` | 看时间：获取当前日期和时间 |
| `web.fetch` | 查天气：请求天气接口，需要接入提供天气数据的服务 |
