# 快速入门：运行你的第一个流程

这一课做一件小事：**输入名字“小明”，得到“你好，小明！”**

你会学会打开流程、修改输入、运行步骤和查看结果。只需要浏览器，不需要写代码、配置 API Key 或下载模型；这是认识流程的第一课，还不调用 AI。

## 1. 打开示例

在本章末尾找到“第一个流程”，点击 **导入示例**，再点击 **在编辑器打开**。

示例保存在文件库的 `handbook-examples/hello/hello.yaml`。重复导入会创建新目录，并为重名流程自动加编号，不覆盖原文件。

编辑器中有两个区域：

- **运行值**：查看和填写本次运行的数据。
- **流程步骤**：查看流程要做什么。本例只有一个“文本模板”步骤。

## 2. 填名字，运行

在“运行值”区域找到 `name`，把“世界”改成“小明”，然后点击 **运行测试**。

页面显示“运行完成”后，`chatOut` 的值应为：

```text
你好，小明！
```

再把 `name` 改成“小红”，点击“运行测试”，结果就会变成“你好，小红！”。修改这里的运行值只影响运行；不要点击“设为默认”，除非你想修改流程的默认值。

## 3. 看懂这个步骤

点击“文本模板”步骤，打开编辑表单。“模板正文”中是：

```text
你好，$name$！
```

`$name$` 表示把 `name` 的值放到这个位置。“保存到变量”是 `chatOut`，表示把生成的问候放进这个变量。

这个流程的工作过程就是：**读取名字 → 生成问候 → 保存结果。**

## 4. 修改一句话，再运行

在同一表单中，把“模板正文”改为：

```text
欢迎，$name$。
```

点击 **应用步骤**，修改会自动保存。然后把运行值中的 `name` 设为“小明”，再次点击 **运行测试**，`chatOut` 应变为：

```text
欢迎，小明。
```

想逐步检查时，也可以点击 **下一步**：本例只有一个步骤，执行一次就完成，结果同样出现在 `chatOut` 中。

## 5. 你已经完成了什么

你刚刚跑通并修改了一个完整流程：`name` 是输入，“文本模板”是步骤，`chatOut` 是输出。这个步骤使用内置的文本处理能力，不需要额外工具。

后续接入 AI 时，可以增加模型调用步骤；需要查询数据时，再增加工具调用步骤。先把这一课的输入、步骤和结果对应起来即可。

## 附：同一个例子的文件和 CLI 运行方式

使用网页教程时不需要编辑下面的代码。它是本章导入示例的原始文件，也可以保存为 `hello.yaml` 后上传到文件库。

```yaml
schemaVersion: 1
name: 手册问候
description: 输入名字，输出一句问候。
fields:
  - name: name
    input: true
    initial: 世界
  - name: chatOut
    output: true
steps:
  - type: template
    template: 你好，$name$！
    output: $chatOut
```

已准备好项目开发环境的用户，可以在项目根目录运行同一个示例：

```powershell
pnpm cli run docs/handbook/examples/hello/hello.yaml --set name=小明 --json
```

结果为：

```json
{"version":1,"ok":true,"result":{"chatOut":"你好，小明！"}}
```

不传入名字时，使用默认值“世界”，结果为“你好，世界！”。CLI 环境准备见 [CLI 使用](cli/guide.md)。
