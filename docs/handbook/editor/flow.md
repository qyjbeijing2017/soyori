# 流程编辑：步骤、源码与保存

在文件库打开流程后，Editor 按执行顺序显示步骤。条件、循环和分组中的步骤会缩进显示。你可以使用表单修改，也可以编辑 YAML / JSON 源码，两种方式修改的是同一个流程。

## 添加和编辑步骤

![步骤参数表单](../images/flow-calling-editor.jpg)

1. 点击“添加步骤”，选择字段操作、条件、循环、模板、运算或调用。
2. 根据表单填写值和字段引用；保存位置选择目标字段。
3. 确认后查看步骤摘要；点击步骤再次编辑。

调用步骤先选工具或子流程，再填写它的输入和输出。必填项与可选高级参数按实际接口显示；各类步骤的完整例子见[概览](../flows/language.md)。

## 顺序、嵌套与分组

![循环体中的顺序步骤](../images/flow-control-editor.jpg)

拖动步骤调整顺序，在条件分支、循环体和分组内部添加对应步骤。缩进显示所属块，不能把流程理解为任意连线。折叠块隐藏细节，不跳过执行；分组里的字段仍按原来的字段名引用。

字段和步骤区域可以分别折叠。手机上先收起暂时不用的区域，再编辑另一部分；长表单向下滚动后确认。手机具体操作见[手机快速入门](../quick-start-mobile.md)。

## 编辑源码与保存

![文件库的 YAML 源码编辑器](../images/flow-control-yaml.jpg)

在文件库中，电脑右键流程选择“源码”；手机使用文件操作菜单选择“源码”。普通脚本与配置文件也可以用源码编辑器打开。编辑器提供高亮和诊断，JSON/YAML 需通过 Core 校验才能作为流程使用。

源码编辑需确认保存；关闭弹窗或退出全屏不表示保存。步骤和字段表单确认后保存到 Library。文件名、流程名称和子流程别名不同，移动或改名不会自动修正所有导入路径。

保存的 `fields` 使用“名称: 配置”组织，分组由 `type: group` 标记，内部继续使用同样的字段写法。旧字段列表可以打开，Editor 保存后会转成新写法，默认值、输入输出和敏感标记保留。

## 选择正确版本运行

Editor 测试使用当前编辑会话，助手 `flow.inspect/run` 读取已保存文件。先保存，再请助手核对相同输入和结果；不要把草稿与已保存版本混在一起比较。

继续阅读[运行与调试](../debugging/guide.md)，学习单步、错误位置与调用栈。
