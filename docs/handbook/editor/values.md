# 流程编辑：字段与当前值

Editor 的“字段”面板展示当前数据，字段设置保存字段声明与默认值。开始新运行时使用初值和输入，执行步骤后可以直接观察变化。

## 添加与设置字段

![字段设置：名称、输入、输出与默认值](../images/flow-variables-editor.jpg)

1. 在字段面板点击“添加字段”，填写不带 `$` 的名称。
2. 根据用途勾选输入、输出，填写说明与默认值。
3. 确认后，字段出现在面板；点击字段名可重新打开设置。

勾选“输入”，允许对话、CLI 命令或父流程给这个字段传入内容；勾选“输出”，流程完成时把这个字段放进最终结果。都不勾选时，它仍可保存内部计算的中间内容。

值输入框按内容自动识别类型，旁边的标签帮助确认。字段设置中的“字段类型”用于选择普通字段或分组；文字、数字、对象等数据类型不需要预先选择。

不用先学会类型才能填写字段。想了解类型的用途和自动识别方式，可以按需阅读[字段类型](../flows/types.md)。

| 输入内容 | 识别结果 |
| --- | --- |
| `10` | 数字 |
| `"10"` | 文字 10 |
| `true` | 布尔值 |
| `null` | 空值 |
| `{name: 小明}` | 对象 |
| `[1, 2]` | 列表 |
| 字段默认值或当前值留空 | 未设置（undefined） |

未设置与 null 不同。默认值和运行输入里的 `$` 保持原文；步骤参数中的 `$count` 才是引用。细节见[字段](../flows/variables.md)。

## 修改字段的当前值

![字段面板](../images/flow-objects-editor.jpg)

在字段右侧编辑当前值，对象与列表使用结构化文字查看或修改内部内容。面板中的当前值与文件默认值分开：试填参数不等于改了流程的默认配置。

当前值与默认值不一致时，可以“重置到默认值”，或用“设置为默认值”将当前可保存的数据写入流程。重置同时清除当前运行会话，下一次执行从头开始。

暂停执行时，按界面允许的操作调整值再继续；部分声明编辑在运行现场中会禁用。工具调用正在执行时不能修改共享执行现场。

## 引用与敏感值

步骤参数选择字段后，YAML 使用 `$count` 或 `$user.name`。字段默认值和当前值是数据，里面的 `$` 不会自动引用其他字段。写入路径、对象和列表行为见[字段路径参考](../flows/operands.md)。

需要遮挡的字段在设置中勾选“敏感值”。眼睛按钮临时显示原值，到时自动隐藏；它不加密、不改变字段的实际值，也不会自动给派生字段传播标记。环境值与流程字段的敏感标记独立，见[环境图文操作](../environment/editor.md)。

字段仍被步骤引用时，清空字段会被阻止，应先移除引用。不要为了整理面板误删流程所需字段。
