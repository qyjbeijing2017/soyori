# 字段：类型

字段可以存放不同的内容，例如一句话、一个数字，或一组搜索结果。“类型”就是用来区分这些内容的名称。

**你不需要先学会字段类型，再开始使用 Soyori。** 我们会尽力让你直接填写需要的内容，由编辑器自动识别，并通过提示帮助你完成操作。本页可以在需要时再查阅。

## 为什么要有类型

不同的内容，处理方式可能不同：

1. **数字**可以用来计算，例如价格、数量和总金额。
2. **文本**用来表达文字，例如问题、回复和翻译要求。
3. **列表**把多项内容放在一起，例如多条搜索结果。

例如，数字 `10` 可以参与计算；文字 `"10"` 也许只是一个编号，需要原样保留。类型帮助步骤和工具正确处理这些内容，也帮助你看懂字段里存了什么。

## 自动识别，不用先选类型

在编辑器中填写字段的默认值、当前值或步骤输入时，编辑器会根据填写的内容自动识别类型，并在旁边显示标签。

![字段旁边会显示当前内容的类型](../images/flow-objects-editor.jpg)

常见的填写方式如下：

| 填写内容 | 自动识别为 | 一般用来做什么 |
| --- | --- | --- |
| `你好` | 文本 | 保存问题、提示词或回复 |
| `10` | 数字 | 保存数量、价格或计算结果 |
| `true` / `false` | 布尔值，也就是“是 / 否” | 保存一个条件是否成立 |
| `[苹果, 香蕉]` | 列表 | 保存多项内容 |
| `{姓名: 小明, 年龄: 18}` | 对象 | 把一件事的多项信息放在一起 |
| `null` | 空值 | 明确表示这里没有内容 |

字段尚未填写、也没有得到结果时，可能显示“未设置”。它和明确填写的空值不同。

**类型描述的是字段当前保存的内容，不是给字段固定贴上的限制。** 创建字段时不用声明它只能放数字或文本，后面的步骤也可以写入不同类型的内容。

## 通常只需关注要填什么

大多数时候，直接填写文字、数字，或者引用已有字段即可。步骤和工具会说明需要什么内容；填写不合适时，再根据提示调整。

如果希望把看起来像数字的内容保留为文字，可以加上双引号。例如，填写 `"001"`，就会保留文字编号 `001`。

直接编辑 YAML 时也一样，通过内容的写法表达类型，不需要另外添加字段类型声明：
