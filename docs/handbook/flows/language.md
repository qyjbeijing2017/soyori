# 概览

流程把数据和操作组织在一起，让你按顺序调用模型、使用工具并处理结果，完成一个任务。

## 从哪里开始

流程通过 YAML 格式的文件定义和保存，格式说明见 [YAML 标准](https://yaml.org/spec/1.2.2/)。你可以使用 Soyori 编辑器，也可以使用任意 IDE 或文本编辑器编辑流程文件。

流程里主要有两部分：字段和步骤。

### 字段：存放要用到的内容

字段就像一个个有名字的收纳格，用来放流程需要的内容，例如用户提出的问题、找到的资料，以及最后的回答。每个字段都有自己的名字，方便后面的步骤找到它。

例如，做一个翻译流程，可以准备两个字段：

1. **原文**：放要翻译的句子。
2. **译文**：放翻译后的结果。

### 步骤：安排要做的事情

步骤告诉流程先做什么、再做什么。例如，请 AI 翻译一段文字、到网上查找资料，或把一段内容保存下来，都可以是一个步骤。

例如，翻译流程中的一个“调用 AI 翻译”步骤，会依次完成：

1. 读取“原文”字段里的句子。
2. 请 AI 将句子翻译成英文。
3. 把翻译结果放进“译文”字段。

需要做更多事情时，就继续添加步骤，按顺序排列。

## 编辑器

在文件库打开流程，即可通过编辑器修改字段和步骤。

![编辑器中的字段和步骤](../images/flow-assignment-editor.jpg)

上方的“字段”保存数据，下方的“步骤”定义要执行的操作。填写参数、调整步骤后，就可以运行流程。

## YAML 文件

一份流程文件主要包含四部分：

| 内容 | 作用 |
| --- | --- |
| `schemaVersion` | 流程格式版本，目前填写 `1` |
| `name` | 流程名称 |
| `fields` | 声明字段及其默认值、输入和输出 |
| `steps` | 按执行顺序排列的步骤 |

例如，下面的流程将数字 `10` 写入 `answer`，并将它作为结果返回：

```yaml
schemaVersion: 1
name: 简单流程
fields:
  answer:
    output: true
steps:
  - type: set
    field: $answer
    value: 10
```
