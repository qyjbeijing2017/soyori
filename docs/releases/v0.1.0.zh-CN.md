# Soyori v0.1.0

[English](v0.1.0.md) | **简体中文**

版本日期：2026 年 10 月 15 日。Git tag `v0.1.0` 标记 Soyori 的首个上线版本。

## 包含内容

- 网页编辑器：Agent 对话、浏览器文件库、字段与步骤编辑，以及逐步调试，适配电脑和手机布局。
- 内置助手：读取手册、管理文件库、创建流程和测试已保存流程。
- Editor 与 CLI 共享流程执行、模型调用、记忆、存储、脚本与工具。网页搜索支持 Mwmbl、Tavily 和博查。
- 开始页引导：一次性入场动画，以及快速开始、对话记忆和工具使用三个教程入口。
- 默认[英文 README](../../README.md)、[中文 README](../../README.zh-CN.md)，以及可在 GitHub 直接阅读的[英文](../handbook/README.md) / [中文](../handbook/README.zh-CN.md)完整手册；每种语言包含 45 个章节、配图和 22 组示例。

## 版本范围

这个 tag 对应完整仓库源码。npm 上的 `soyori-*` 包 `0.1.0` 已于 10 月 14 日从较早的 `5ff959f` 源码发布，本次创建 tag 不会更新这些包。使用当前记忆接口和 Agent 示例时，请按手册说明从源码构建。详见 [npm 发布记录](../npm-release.md)。

关闭页面后不能恢复运行现场。浏览器本地文件与配置不会自动同步到电脑目录或其他设备。本地模型推理取决于设备和浏览器；手机布局支持不代表所有手机都能运行本地模型。

## 验证

上线检查包括 `pnpm verify`、Editor 生产构建、手册目录一致性，以及文档本地链接、图片和小节锚点。三个开始页教程入口已在浏览器检查，包括手机快速入门跳转。
