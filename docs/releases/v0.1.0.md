# Soyori v0.1.0

**English** | [简体中文](v0.1.0.zh-CN.md)

Release date: October 15, 2026. The `v0.1.0` Git tag marks Soyori's first launch version.

## Included

- Web Editor with Agent chat, a browser file Library, editable fields and steps, and step-by-step debugging on desktop and mobile layouts.
- A built-in assistant that can read the handbook, manage Library files, create flows, and test saved flows.
- Shared flow execution, model calls, memory, storage, scripts, and tools for Editor and CLI. Web search supports Mwmbl, Tavily, and Bocha.
- A welcome screen with a short entrance animation and links to quick starts, conversation memory, and tool use.
- An English default [README](../../README.md), a [Chinese README](../../README.zh-CN.md), and the complete [English](../handbook/README.md) / [Chinese](../handbook/README.zh-CN.md) handbook on GitHub. Each language includes 45 chapters, screenshots, and 22 example groups.

## Version scope

This tag identifies the complete repository source. The npm `soyori-*` packages at `0.1.0` were published on October 14 from the earlier `5ff959f` source revision; creating this tag does not update those packages. For the current memory interface and Agent examples, follow the handbook's source-build instructions. See the [npm release record](../npm-release.md).

Runtime state cannot be resumed after closing the page. Browser-local files and settings do not automatically sync to disk or other devices. Local model inference depends on the device and browser; mobile layout support does not guarantee local model compatibility on every phone.

## Verification

The launch checks cover `pnpm verify`, the Editor production build, handbook index consistency, and local documentation links, images, and section anchors. The three welcome-screen tutorial links were also checked in the browser, including the mobile quick-start destination.
